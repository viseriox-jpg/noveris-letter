# Bird courier assets

This branch incorporates selected bird model/animation/texture assets from the user-provided Frikinzi's Fauna 1.8.0.3 (Minecraft 1.20.1) archive for use as Noveris Letter courier visuals.

- Source archive: `frikinzis-fauna-1.8.0.3-1.20.1-RELEASE.jar`
- Source mod: Frikinzi's Fauna
- Integrated source assets: Raven and Barn Owl model/animation/texture files.
- The Sparrow courier uses a small Noveris Letter GeoModel/animation adaptation with the source mod's sparrow texture.
- Per user authorization, these assets are being incorporated into this project.

The gameplay integration is implemented for Minecraft 1.21.1 NeoForge and does not load the original 1.20.1 Forge mod at runtime.
