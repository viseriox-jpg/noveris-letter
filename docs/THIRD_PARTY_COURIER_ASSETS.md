# Third-party courier assets

The courier appearances in this branch use the models, animation definitions and textures from **Clutter: Bestiary 1.1.2-NeoForge-1.21.1**.

The build imports only the required courier model/animation classes and the five requested textures into `Noveris Letter`; the Clutter mod itself is not bundled as a runtime dependency.

Requested appearances:

- Mossbloom
- Coati
- Red Panda
- Booplet
- Capybara

The imported source release is MIT-licensed.
