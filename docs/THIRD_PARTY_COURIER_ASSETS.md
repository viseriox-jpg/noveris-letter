# Third-party courier assets

The five ground courier appearances in this branch use the exact model, texture and animation resources extracted from the supplied **Crop Critters 1.5.0 NeoForge 1.21.1** JAR.

Imported appearances:

- Melon Critter
- Carrot Critter
- Wheat Critter
- Pumpkin Critter
- Potato Critter

The four standard critters use Crop Critters' supplied `basic_critter.animation.json`; Pumpkin Critter uses its supplied `pumpkin_critter.animation.json`. The original geometry and textures are copied without model conversion.

The only preserved non-Crop-Critter couriers are the Sparrow and Barn Owl. No Clutter Bestiary courier assets remain in the build.
